Security Dashboard

Advanced cybersecurity features protecting your data locally.

🔒 Local Encryption

All files are encrypted with AES-256-GCM before storage. Encryption keys never leave your device.

ACTIVE AES-256-GCM

🛡️ Memory Protection

Sensitive data is cleared from memory after use. No persistent storage of unencrypted data.

ACTIVE Zero-trust memory

🔐 Secure Key Management

Encryption keys are derived from your master password using PBKDF2 with 100,000 iterations.

ACTIVE PBKDF2-SHA256

📁 Secure File Storage

Files are stored in IndexedDB with additional encryption layer. No cloud synchronization.

ACTIVE IndexedDB + Encryption

⚠️ Offline Operation

Application works completely offline. No network requests are made, preventing data leaks.

OFFLINE MODE No network access

🔍 Integrity Checking

All files include HMAC verification to detect tampering. Corrupted files are automatically rejected.

ACTIVE HMAC-SHA256
